# 界面与运行时行为

## 布局

整体沿用 RcHarness 的窄图标侧栏、顶部标题与映射开关、设备状态卡片。侧栏对应功能使用 SF Symbols，Harness 使用与 RcHarness 同款的自绘图标；常用语统一使用简洁的线性气泡 `text.bubble`，覆盖侧栏、常用语库标题和空状态。侧栏图标采用常规字重与单色显示，未选中状态使用更高对比度；固定行高、图标槽和 24 pt Harness 网格使图形落在整数坐标，减少细小尺寸下的发虚。窗口最小内容尺寸为 1020 × 772，标题栏融入页面。页头高度 94 pt、页面内边距 24 pt、面板圆角 16 pt，直接沿用 RcHarness 的语义样式、面板、开关和方案命名弹窗。其他设置页使用统一的圆角面板与间距。

映射页固定显示方案选择、绑定应用图标、居中的手柄示意图与两侧按键卡片。连线标出卡片对应的实体按键。按键卡片按单只手柄的实体布局显示，C 键仅出现在二代右手柄上。最小窗口无需滚动即可访问全部映射。每张卡片提供单击、双击、长按三个编辑入口，悬停与实时按下在卡片、连线和手柄图上同步高亮。底部提供连接与摇杆、常用语和管理方案入口。消息显示在右上角。

映射页同时显示实体按键与底部四张摇杆方向卡片，手柄示意图上的按键和摇杆箭头均可点击编辑，无需切换页面。左右摇杆的方向按方案分别保存，不与十字键或摇杆按下共用绑定。方向默认为对应方向键，清除后可单独禁用；保存方向动作不改变摇杆模式，只有方向映射模式执行这些动作。

固定功能「切换左摇杆模式」「切换右摇杆模式」可绑定任意按键或方向的单击、双击、长按，在鼠标模式和方向映射之间切换，默认使用方向映射。按住或重复输入报告不会重复切换，暂停时不执行切换。切换时释放旧方向键并取消该侧待识别方向手势，摇杆需回中后再触发新模式，避免旧偏转意外移动指针或执行方向动作。映射页显示当前模式并通过消息提示切换结果。切换仅改变运行时状态，更换选中手柄、应用方案或修改活动配置后恢复默认的方向映射。切换功能与暂停、常用语选择器一样，不允许作为组合动作步骤。

摇杆拨动支持单次、连续两次及保持方向，对应单击、双击、长按；双击和长按沿用 0.30s / 0.55s 识别时间。方向从经过校准和死区处理的向量识别，进入阈值为 0.3、退出阈值为 0.2，减少边界抖动；斜向可同时按住两个方向，回中释放。选中新设备后需先回中再触发方向。连续 0.5s 未收到输入会释放方向并取消待识别手势；暂停、断连、方案变化、编辑和退出同样取消方向动作。统计把左右摇杆的各方向独立记录。

## 输入

两代各有独立协议层，共用动作引擎。允许多个手柄保持连接，但只有选中的物理设备进入动作引擎、实时按键高亮与统计；同型号设备以标识后缀区分。非选中手柄不会发送按键、移动指针、滚动或恢复暂停。只将按键边沿交给手势识别，重复输入报告不触发重复按下。

顶部设备卡、连接页和菜单栏使用同一选择。初次使用选中第一只就绪设备；先选择离线型号时等待该型号。选择精确保存物理 ID，断线、休眠、扫描和重启后保留，不自动切到其他设备。切换会释放旧按键/方向键、清除旧摇杆状态、取消手势与组合动作。切换和重连后已经按下的按键需先松开再按，偏转的摇杆需先回中，避免新设备的旧输入直接执行。

窗口的手柄下拉菜单和菜单栏的「当前」子菜单始终显示四个型号。每个型号列出所有已连接的手柄，没有连接时显示型号名称和灰点，仍可选择该型号。断线后顶部设备卡和连接页选择控件保留型号名称，不显示断联设备的硬件 ID。连接页的「手柄设备」只显示已连接的手柄，列表为空时显示配对提示。

单击默认按住直传。配置双击时，第一次松开后最多等待 0.30s；配置长按时等待 0.55s，长按动作发一次点击。手势从首次按下捕获映射，编辑后不把旧按下配上新松开。

暂停保留暂停前的模式切换键，即使前台应用更换了方案，也有恢复入口。菜单栏始终可恢复。暂停不排他占用手柄、不隐藏系统手柄、不屏蔽其他程序的原生输入。

断线清除对应设备的输入；选中设备断线时取消待识别手势与组合动作并释放按键，其他设备断线不影响当前映射。方案切换、编辑、暂停、退出、休眠取消当前合成动作和组合动作。输入停止 0.5s 后停止摇杆动作，2s 后释放该设备按住的按钮，防止蓝牙断开回调延迟导致卡键。

左右摇杆默认使用方向映射。切换到鼠标模式后，偏转越大，指针移动越快，回到死区时停止。原始 12 位中心默认 2048，径向死区默认 18%。每设备可手动校准中心。连接时沿用设定的中心值和默认极值。

连接页的「鼠标模式设置」可按 Joy-Con 型号分别选择鼠标左键和右键。候选按键排除摇杆、摇杆按下和当前配置的全局按键，左右键不能绑定同一个按键。绑定只在对应摇杆处于鼠标模式时生效，按住按键并移动摇杆会生成拖动事件。选中的手柄在鼠标模式下启用映射时，菜单栏图标采用 Logo 的彩色配色，方向映射、暂停和未连接时使用单色版。

## 方案与配置

未绑定应用使用默认方案。启用的 Harness 在应用成为前台时选择其方案；多个应用可共用方案。在键位方案页右键点按方案可设为默认。新建和复制后进入按键映射页，复制时同时弹出重命名窗口。按键映射页也可通过方案旁的铅笔按钮重命名。编辑选择单独持久化。删除方案会同步删除自定义 Harness 绑定，内置 Harness 改用剩余默认方案并保留启用状态，至少保留一个方案。删除确认说明具体影响。映射页的绑定状态提示会显示不同于当前编辑方案的活动方案。

内置 ChatGPT、Claude、Cursor、DeepSeek、WorkBuddy、OpenCode 六套应用方案，复用对应组合动作，适用于一、二代左右 Joy-Con。方向键 ↑/→/↓/← 与右手柄 X/A/B/Y 的双击对应四个导航槽，L/ZL 与 R/ZR 的双击对应第五、六槽；ChatGPT 为最近聊天 1–6，Claude 为环境 1–6，OpenCode 为会话标签页 1–6，其他应用为面板、任务和模型等常用操作。双击摇杆新建会话，长按摇杆打开常用语；双击 −/+ 执行应用主菜单动作，长按执行新环境、新窗口等辅助动作；双击 SL/SR 切换前后会话或任务，DeepSeek 为分割面板/面板全屏。默认全局按键保留音量单击和 HOME 暂停。全局动作只覆盖已设置的手势，因此 −/+ 双击和长按可沿用当前方案。设置双击后单击按手势识别规则延后触发。

首次启动、升级和导入配置时补齐六套应用方案。新增内置 Harness 自动绑定同名方案；已有 Harness 绑定（包括旧版共享默认方案）保持原样，可在 Harness 页自行切换。预设使用稳定 ID 和版本标记，保留用户重命名、编辑和删除；同名自定义方案不被覆盖，新增预设名称自动追加序号。已删除的组合动作不会被方案补齐流程恢复，相应初始映射留空。最多支持 100 个自定义方案，另加 6 个内置方案。

动作支持快捷键、启动应用、直接 Unicode 文本输入、唤出常用语、打开并聚焦六套内置 Harness 的输入框与组合动作。常用语库与 RcHarness 保持一致，包含 16 条中英文内容、五向分配、单击输入内容 1、双击输入内容 2；在按键映射中可把“唤出常用语”绑定到左或右摇杆按下，打开悬浮选择器，B、HOME 或 Esc 关闭。组合动作顺序执行，在每一步后等待指定秒数；新动作取消旧动作，禁止递归组合。按键映射编辑弹窗和组合动作快捷键录制期间暂停发送手柄事件。浏览组合动作页时仍可使用手柄。

常用语页沿用 RcHarness 的固定三栏结构，列表与内容编辑区独立滚动；分配面板宽 252 pt、常用语库宽 232 pt。已分配条目按上、下、左、右、A 置顶，同一条语句只显示一次并列出全部分配位置；未分配条目可拖动排序，也可用上移和下移按钮调整，解除分配后回到用户保存的顺序。分配弹窗打开时聚焦独立搜索，支持标题、正文与内容 2 的模糊匹配、多关键词和大小写／全半角归一，标记当前分配，支持清空搜索和不分配。删除已分配条目前显示受影响位置；删除后可在窗口底部连续撤销，恢复内容、顺序与分配，原位置已另作分配时保留新分配并提示冲突。直接输入文本和组合动作保存的是文本副本，不随常用语删除而移除。

导入配置先做版本、唯一 ID、范围、方案引用与步骤校验，通过后整体替换；导入和导出共用 2 MB 文件大小上限。导出会在写入前检查大小。无法解码的本机配置保留 recovery 副本。导出只包含配置，不包含统计。统计按本地日期记录按键次数，不保存输入文本。

设置页版本区提供「检查更新…」和版本历史入口。Sparkle 原生窗口负责显示版本、下载、校验签名并重启安装；「自动检查更新」默认关闭，开启后只自动检查，安装仍需用户确认。相同展示版本不会被更高构建号触发升级，只有线上 `CFBundleShortVersionString` 高于本地时才作为更新候选。校验失败、兼容性不满足或 Sparkle 无法启动时，不改变主面板操作提示；失败详情写入设置日志，版本区保留上次检查时间或「尚未检查更新」。截图模式和测试使用预览模型，不启动真实更新器。
